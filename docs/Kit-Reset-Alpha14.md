# Alpha14 — EMU / HSR kit reset

This release deletes the old EMU and HSR designs completely from the active mod. It removes their blocks, items, block entities, renderers, models, textures, sounds, recipes, QuickBuilds, previews and generators. Both kits will be redesigned from scratch later.

The active vehicle kits are Gondola and LRT. Fare equipment, platform screen doors, elevators, floor markers and linked bank calls are retained. Corrected elevator opening sounds and silent closing are retained.

Existing EMU/HSR builds are incompatible with this release because those block registrations are removed. Use this patch in worlds where you accept removal of the old kits. Replace the previous Create Transit JAR rather than installing both versions.

The inventory divider redesign and escalator/travelator kit are still concept plans; this patch removes the retired kits only.
