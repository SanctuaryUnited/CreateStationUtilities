# Create: Station Utilities V18.4

- Right-click a connected escalator or travelator with a Create Wrench to open its settings. Apply updates the entire loaded run. Choose Slow, Normal, or Fast, reverse the belt, set both dye colors, or toggle running sounds. Normal retains the previous speed. Redstone still controls operation.
- Radio settings for cabin and station speakers add bass boost (0 to +6 dB), distance falloff, and wall muffling. Each speaker keeps its acoustic settings when grouped. Extended reverb retains its range and level controls.
- Sound Physics Remastered can process positional elevator chimes, door and motor sounds, and escalator running loops. It is optional and only needed on the client for these effects.
- Update both the client and server to V18.4 for multiplayer.

Minecraft 1.21.1, NeoForge 21.1.248, Java 21.
